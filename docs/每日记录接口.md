# 每日记录：Claude 怎么把对话写进健康簿

用户每天在对话里说一次当天的生活，Claude 整理成一条 JSON，发到：

```
POST https://<你的域名>/api/checkin      （Basic 认证，和看板同一个账号密码）
Content-Type: application/json
```

同一天重复发会覆盖这一天（状态变回「待确认」），用户在首页「今日记录」里确认、修改或撤销。
手表、体重秤、经期等自动同步的数据不要写进来，页面会自己读；手表已有的同一场运动页面会自动合并，不会重复计时。

```json
{
  "member_id": "me",
  "date": "2026-11-07",                 // 实际发生的日期，补录就写那天
  "text": "用户原话（可选）",
  "meals": [ { "meal": "早餐", "items": ["鸡蛋", "豆浆"], "tags": ["蛋白质", "豆类"] } ],
  "exercise": [ { "type": "网球", "minutes": 60, "rpe": 6, "sets": "深蹲 30kg 3×10", "pain": "", "note": "" } ],
  "skin": { "note": "下巴新冒两颗痘" },
  "care": ["面膜"],                      // 做了的护理，会更新对应护理项目的「上次」
  "feel": "有点累",
  "sleep_feel": "睡得不好",
  "supps": [ { "name": "D3", "servings": 1 } ],   // 说吃了的补剂（按补充用药里的名称或别名匹配）；没说就不写
  "symptoms": [ { "name": "头痛", "severity": 3, "note": "下午" } ],
  "nutrients": { "protein": "70–90 g", "fiber": "15–20 g", "calcium": "约 400–600 mg", "vitd": "约 200–400 IU", "omega3": "约 1000 mg" },  // 可选，食物部分的粗略区间
  "body": { "waist": 70 },               // 可选，量了腰围才写
  "protein": "大致够 / 偏少",            // 可选，拿不准就不写
  "energy": "1600–2000 kcal",            // 可选，只写范围；份量不清楚就不写
  "advice": ["最多 3 条，用词保守"],
  "questions": ["最多 1–2 个可跳过的追问"],
  "notes": ""
}
```

meals 里可以用 `"food_id"` 引用常吃食物库（「早餐老样子」）。

还可以带 `goals`、`routines`、`products`、`foods`、`meds` 数组（有 id 就更新，没有就新建），例如用户说「我现在用 xx 精华（烟酰胺）」：

```json
{ "member_id": "me", "products": [ { "name": "xx 精华", "cat": "精华", "ingredients": ["烟酰胺"], "when": "both", "status": "using" } ] }
```

补充用药（和处方药同一张表，`cat` 写 supplement）：

```json
{ "member_id": "me", "meds": [ { "cat": "supplement", "kind": "long", "name": "xx 维生素 D3", "alias": ["D3"], "nutrients": [ { "name": "维生素 D3", "amount": 1000, "unit": "IU", "key": "vitd" } ], "dose": "每次 1 粒", "freq": "每天 1 次", "reason": "", "start": "2026-11-07", "end": "" } ] }
```

nutrients 的 key：vitd、vita、omega3、calcium、iron、mag、zinc、vitc、b12、folate、vitk、protein。训练计划：`goals` 里 `{ "kind": "plan", "sport": "网球", "per_week": 2 }`；常吃食物：`foods` 里 `{ "name": "早餐杂粮米糊", "items": [...], "portion": "一碗约 300 ml" }`。

tags 可选值：蛋白质、鱼虾、豆类、蔬菜、水果、全谷物和薯类、奶类、坚果、甜食和含糖饮料、油炸（页面也会按关键词自动补）。
原则：没说的就不写（显示「未记录」，不是 0）；不编造精确热量；不诊断、不建议补剂剂量。
